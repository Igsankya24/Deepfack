# 🎭 Deepfack  

> Real-time **Face Swap, Face Animation, and AI-Powered Video Manipulation** using deep learning.  
> Built with **Python, ONNX, DirectX, and GPU acceleration**.

## 🚀 My Contributions  
- Implemented **AI-powered real-time face swap** with multiple pretrained models  
- Integrated **single-photo face swap (Insight)** for lightweight usage  
- Added **face animation module** to bring static images to life using webcam/video input  
- Optimized the project for **GPU acceleration (DirectX12, RTX/RX cards)**  
- Documented setup guides for **Windows & Linux environments**  
- Improved overall **UI/UX for streaming & video call integration**

## 🖥️ System Requirements  
- **GPU:** DirectX12 compatible (RTX 2070+ / RX 5700 XT+ recommended)  
- **CPU:** Modern CPU with AVX instructions  
- **RAM:** 4GB minimum (32GB+ paging file recommended)  
- **OS:** Windows 10 / Linux
